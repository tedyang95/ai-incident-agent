③ 面试怎么讲这 100 行（逐句弹药）

Opening："I designed the LLM workflow that orchestrates the whole triage — it's the core of the agent."
Context collection："The agent gathers evidence before reasoning: it calls tools (Prometheus for metrics, Loki for logs) and retrieves runbooks via RAG — so the LLM never hallucinates from nothing, it reasons from real data."
Structured output："I used prompt engineering to force a JSON schema (root cause, confidence, actions), then parse it — this makes the output machine-readable, not just chat text."
Robustness："Every step has a fallback — if the LLM fails, the incident is marked FAILED with raw context preserved for manual review. I track tokens and latency per call for cost monitoring."
Why it matters："This is L2-L4 on the AI product stack — grounded AI (RAG) + tool-using + workflow — the difference between a chatbot and a system."
